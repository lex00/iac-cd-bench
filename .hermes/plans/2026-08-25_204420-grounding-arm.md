# Schema-Grounded Benchmark Arm Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a `--grounding` arm to iac-cd-bench that appends the exact upstream CRD schemas for each task seed's kinds to the model prompt, enabling paired memory-vs-grounded runs.

**Architecture:** A new `bench/grounding.py` module talks to the Flux Schema MCP server (`https://schemas.fluxoperator.dev/mcp`, stateless streamable HTTP, no auth) over JSON-RPC with a disk cache under `.cache/schemas/`. The runner grows a `--grounding` flag; after `materialize_task()` it scans the workspace YAML for `apiVersion`/`kind` pairs, fetches matching schemas (cached), and appends them to the prompt as a fenced reference section. Results land in tagged dirs (`--results-tag grounded`) so nothing clobbers baselines. Scoped to `knr-ops` and `crossplane` stacks; the runner refuses `--grounding` on other stacks with a clear error.

**Tech Stack:** Python 3.14 (repo venv), httpx (already a dependency via adapters), stdlib json/re/pathlib. Tests via pytest (already configured, `make test`).

**Issue:** polarsquad/knr-ops issue "Benchmark: schema-grounded agent arm using the Flux Schema MCP catalog" (user approved filing; track the PR against it).

```python
# bench/grounding.py
"""Schema grounding: fetch upstream CRD schemas from the Flux Schema MCP catalog."""
from __future__ import annotations

import json
import re
from pathlib import Path
from typing import Any

MCP_URL = "https://schemas.fluxoperator.dev/mcp"
EXEMPT_GROUPS = ("platform.example.org",)  # XRDs defined in the task seed itself


class MCPClient:
    """Stateless streamable-HTTP JSON-RPC client (server assigns no session id)."""

    def __init__(self, transport=None, url: str = MCP_URL, timeout: float = 60.0):
        self._url = url
        self._timeout = timeout
        if transport is None:
            import httpx
            self._transport = httpx.Client(timeout=timeout)
        else:
            self._transport = transport
        self._next_id = 0

    def _call(self, method: str, params: dict | None = None) -> dict:
        self._next_id += 1
        payload = {"jsonrpc": "2.0", "id": self._next_id, "method": method}
        if params:
            payload["params"] = params
        resp = self._transport.post(
            self._url,
            headers={"Content-Type": "application/json", "Accept": "application/json, text/event-stream"},
            json=payload,
            timeout=self._timeout,
        )
        data = self._parse(resp)
        if "error" in data:
            raise RuntimeError(f"MCP error: {data['error']}")
        return data.get("result", {})

    @staticmethod
    def _parse(resp) -> dict:
        ct = resp.headers.get("content-type", "")
        body = resp.text
        if "text/event-stream" in ct:  # SSE-framed fallback
            for line in body.splitlines():
                if line.startswith("data:"):
                    try:
                        return json.loads(line[5:].strip())
                    except json.JSONDecodeError:
                        continue
            raise RuntimeError("SSE response with no parsable data frame")
        return json.loads(body)

    def get_schema(self, kind: str, api_version: str) -> str:
        result = self._call("tools/call", {"name": "get_schema", "arguments": {"kind": kind, "apiVersion": api_version}})
        return result["content"][0]["text"]

    def grep_catalog(self, query: str) -> str:
        result = self._call("tools/call", {"name": "grep_catalog", "arguments": {"query": query}})
        return result["content"][0]["text"]
```

```python
def discover_kinds(workspace: Path) -> list[tuple[str, str]]:
    """Return (apiVersion, kind) pairs found in workspace YAML files."""
    pairs: list[tuple[str, str]] = []
    pattern = re.compile(r"apiVersion:\s*(\S+)\s*\nkind:\s*(\S+)")
    for f in sorted(workspace.rglob("*.y*ml")):
        try:
            text = f.read_text()
        except (UnicodeDecodeError, OSError):
            continue
        for m in pattern.finditer(text):
            api_version, kind = m.group(1), m.group(2)
            if api_version.split("/")[0] in EXEMPT_GROUPS:
                continue
            if (api_version, kind) not in pairs:
                pairs.append((api_version, kind))
    return pairs
```

```python
class SchemaCache:
    """Disk cache keyed by kind+apiVersion; falls back to fetch on miss."""

    def __init__(self, cache_dir: Path):
        self.dir = cache_dir
        self.dir.mkdir(parents=True, exist_ok=True)

    @staticmethod
    def _key(kind: str, api_version: str) -> str:
        safe = f"{kind}_{api_version}".replace("/", "_")
        return f"{safe}.json"

    def get(self, kind: str, api_version: str, fetch) -> str:
        path = self.dir / self._key(kind, api_version)
        if path.exists():
            return path.read_text()
        schema = fetch(kind, api_version)
        path.write_text(schema)
        return schema

    def warm(self, pairs: list[tuple[str, str]], client: MCPClient) -> int:
        """Prefetch a set of pairs; return count newly fetched."""
        n = 0
        for api_version, kind in pairs:
            if not (self.dir / self._key(kind, api_version)).exists():
                self.get(kind, api_version, client.get_schema)
                n += 1
()        return n
```

## Risks, tradeoffs, open questions

- **Schema bloat**: full `Kustomization` schema ~9k tokens x several kinds could crowd context for small-context models. Open: cap kinds per task (e.g. top-N by seed frequency) or use `grep_schema` for field-level excerpts. Decision deferred to pilot evidence.
- **Endpoint uptime**: free public service. Cache-first design means a down endpoint blocks only cache misses; pilot should warm the cache while connectivity is good.
- **Cold-condition requirement**: cold dirs for existing models may not exist (most suites ran warm); pilot pairs cold vs cold+grounded on fresh runs, no historical confound.
- **Comparison fairness**: grounded input includes schemas, so input-token comparisons must separate prompt base vs schema section (Task 5 records section chars for exactly this).
- **Open question for maintainer**: whether `platform.example.org` XRD exemption should extend to any future in-seed XRDs via a convention (e.g. `seed/xrd/` dir) instead of a hardcoded group.
